# Imagens — História, 9º ano (Solar Colégios)

Catálogo de imagens do livro, para consulta e escolha.

**Site:** https://gereneto.github.io/imagens_hist_9/

## O que há aqui

O site tem duas seções, acessíveis pelas abas no alto de qualquer página:

- **Selecionadas** — todas as imagens que já estão nos textos das unidades 1 a 10, com a
  identificação de cada uma: o que é, de onde veio, em que licença está e se existe uma
  versão melhor no Wikimedia Commons.
- **Sugeridas** — imagens novas, numeradas, para preencher trechos sem ilustração
  (*lacuna*) ou para substituir uma imagem já presente (*substitui a imagem N*).

Há ainda uma terceira página, **Pendências de direitos**, ligada a partir do início: reúne
as imagens do livro para as quais não se achou versão de licença livre.

Abaixo das abas ficam os números das unidades. A unidade em que você está aparece
destacada; as cinzas ainda não têm imagens catalogadas.

## Como escolher

Cada cartão tem um número. Para indicar o que deve entrar no livro, basta passar os
números — por exemplo, "Sugeridas U4: 3, 7, 11".

## Licenças

A cor do texto da licença indica o que é possível fazer:

| Cor | Significado |
|---|---|
| **Verde** | Domínio público ou CC0 — uso livre. |
| **Laranja** | Creative Commons BY ou BY-SA — uso permitido com crédito ao autor na legenda. |
| **Vermelho** | Licença não livre ou não identificada — não usar sem autorização. |

Confira sempre a página do arquivo no Commons antes de diagramar: a licença pode mudar.

## Arquivos

As imagens em alta resolução não ficam neste repositório. Elas estão no computador do
projeto, em `Imagens/<unidade>/atuais` e `Imagens/<unidade>/sugeridas`, numeradas na
mesma ordem do site. O caminho de cada arquivo aparece no rodapé do seu cartão.
